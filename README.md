## Features

- Periodic distance measurement with an HC-SR04 ultrasonic sensor
- Alarm triggers when an object is closer than 20 cm (fixed in code)
- Alarm pitch adjustable from 200 Hz to 3000 Hz with a 10 kΩ potentiometer
- Tone generated in software on a passive buzzer
- Serial Monitor output showing distance and current frequency

---

## Hardware

| Component | Role |
|---|---|
| NodeMCU ESP8266 | Microcontroller |
| HC-SR04 | Ultrasonic distance sensor |
| Passive buzzer | Audible alarm (tone driven by software) |
| Potentiometer (10 kΩ) | Alarm frequency adjustment |

---

## Wiring

| Part | Pin | Connects to |
|---|---|---|
| HC-SR04 | TRIG | D5 |
| HC-SR04 | ECHO | D6 |
| Passive buzzer | + | D7 |
| Passive buzzer | - | GND |
| Potentiometer | Middle pin | A0 |
| Potentiometer | Outer pins | 3V3 and GND |

> **Note:** The HC-SR04 ECHO pin outputs 5 V. For long-term use, add a voltage divider or level shifter before connecting it to the ESP8266 GPIO pin.

---

## How It Works

1. The HC-SR04 measures the distance to the nearest object (`pulseIn` on ECHO, converted to cm).
2. The potentiometer value is read from analog input `A0` (0-1023).
3. The analog value is mapped to a frequency between 200 Hz and 3000 Hz.
4. If the distance is below 20 cm, the buzzer plays a 100 ms tone at that frequency.
5. Otherwise the buzzer stays off.
6. The cycle repeats continuously.

Decision logic:

```text
IF distance < 20 cm:
    play tone (frequency from potentiometer, 100 ms)
ELSE:
    buzzer OFF
```

The tone is generated by toggling the buzzer pin HIGH/LOW at the target frequency, which is why a **passive** buzzer is required. An active buzzer has its own oscillator and would ignore the frequency changes.

## Getting Started

1. Install the **ESP8266 board package** in the Arduino IDE.
2. Select the appropriate **NodeMCU ESP8266** board.
3. Connect the NodeMCU through USB.
4. Open `simple_buzzer_potentiometer.ino` and upload the sketch.
5. Open the Serial Monitor at **115200 baud**.
